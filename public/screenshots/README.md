# Install-dialog screenshots

Every `.png` here is added to the web manifest automatically (see
`manifestScreenshots()` in `vite.config.ts`), in filename order. Portrait
images are `narrow` (phones), landscape are `wide` (desktop). Keep the aspect
ratio under 2.3:1 and each side between 320 and 3840 px.

Target set, in this order (same for PWABuilder / Play):

1. `01-table.png`   — the dinner table (tone-setter)
2. `02-brief.png`   — the secret brief assigned to you
3. `03-allergies.png` — the allergy / diet panel
4. `04-ballot.png`  — voting
5. `05-results.png` — winning chef
6. `06-album.png`   — the dinner album

`01-table.png` is a placeholder from an early test dinner: replace it.
